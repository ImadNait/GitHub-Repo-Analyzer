# GitHub Repo Analyzer

An AI agent that analyzes any GitHub repository and generates a structured report.
Built with LangChain, LangGraph, and Groq (Llama 3.3).

## What it does
- Fetches repo info, README, file structure, languages, and recent commits
- Generates a full analysis report using AI
- Saves the report locally

## Tech Stack
- LangChain + LangGraph
- Groq API (llama-3.3-70b-versatile)
- GitHub REST API
