**GitHub Repository Analysis Report**
=====================================

### 1. Project Overview

The ImadNait/GitHub-Repo-Analyzer project is an AI-powered agent designed to analyze any GitHub repository and generate a structured report. The project utilizes LangChain, LangGraph, and Groq (Llama 3.3) to fetch repository information, README, file structure, languages, and recent commits, and then generates a comprehensive analysis report using AI.

### 2. Tech Stack

The project's tech stack consists of:

* **LangChain + LangGraph**: Used for building the AI agent
* **Groq API (llama-3.3-70b-versatile)**: Utilized for generating the analysis report
* **GitHub REST API**: Used for fetching repository information
